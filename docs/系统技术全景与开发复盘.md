# 零件分拣机器人系统 —— 技术全景与开发复盘

> 本文档记录系统完整架构、关键参数基准矩阵与逐阶段攻关历程，是项目的技术资产归档。

## 1. 系统架构

本项目采用 **双核心异构协同控制架构**：

- **边缘视觉计算层（K230）**：运行 MicroPython 与端侧 YOLOv8 目标检测网络，完成物料分类（立方体 / 圆柱体 / 棱柱体）、二维空间对准中心计算以及距离/深度比例特征提取，通过非阻塞 UART 向下位机广播规整结构化数据。
- **运动与位姿控制层（Arduino）**：负责双路直流减速电机（履带底盘）差速控制、四路红外循迹闭环、侧方测距红外感知，以及由 4 个高精度舵机构成的机械臂平滑运动学执行。

完整作业流水线：

```
起点视觉对准抓取 → 黑线爆发直冲 → 动态 PID 巡线与侧向投递 → 闭环特征点直角弯 → 终极五步法泊车入库 → 起点复位
```

## 2. 核心里程碑与攻关记录

### 2.1 边缘视觉层高可用性重构（K230）

1. **轻量纯净部署**：剔除此前引发堆内存溢出（Core Panic）的重度传统图像处理算子（如 `image.find_rects`），固化纯端侧 YOLOv8 推理流程。
2. **硬件看门狗双重容错（WDT & Soft Reset）**：
   - 引入 `machine.WDT(1, 5)`，初始化完成后开启，主循环仅当取帧、推理、OSD 绘制与 GC 完整走通后方才 `wdt.feed()`，超时 5 秒未响应自动硬件复位。
   - 主循环 `except Exception` 捕获异常后主动 `machine.reset()`，保证长期无监督运行自愈。
3. **优先级仲裁与输出阻尼**：抓取优先级固化为 `[2, 0, 1]`（棱柱体 → 立方体 → 圆柱体），通信频率严格限制 100ms 一帧。

### 2.2 通信链路解耦与全域非阻塞架构（Arduino）

1. **流式字符组装缓冲区**：抛弃 `while(Serial.available()) Serial.read();` 粗暴清空，改为按字符非阻塞累加至 `serialBuffer`，遇 `\n` 切分置位 `newMsgReady`，杜绝半截数据损坏。
2. **消灭延时死等**：引入 `STATE_WAITING` 状态与 `initiateWait()`，将电机惯性制动、阶段切换的阻塞 `delay` 全部替换为基于 `millis()` 的非阻塞轮询，保证 `UpdateServoSmooth()` 高频执行。

### 2.3 底盘转弯与泊车控制体系闭环化

1. **直角弯防抖与回正**：`STATE_CORNER_CONFIRM` 确认丢线后转 `STATE_CORNER_LEFT`，`cornerLeftDebounce` 连续 3 次压线滤波，确认回正后注入短时左转摆正 + 前进冲量。
2. **终极五步泊车法（`STATE_PARK_TURN2`）**：左旋找全白 → 倒转右侧探头挂线 → 前进左侧探头触线 → 前进冲出黑线 → 左转右侧重新挂线，完全靠传感器跳变自动推进，摆脱盲转计时误差。
3. **启动脉冲破静摩擦**：切入前向校准瞬间注入 `motorControl(150, 140); delay(30);` 短冲量，克服转弯后低速静摩擦死区。
4. **后退盲退直停**：`STATE_PARK_REVERSE_TRACKING` 纯对称盲退 `(-118, -118)` 持续 3600ms，到点精准停驻。

### 2.4 红外投递防误触与复位门禁

1. **起步盲区保护**：循迹前 9 秒屏蔽红外，防止出发区误触发。
2. **离开双重防重触发**：投放后需连续 20 次无障碍且脱离超 800ms，才允许下一次识别。

## 4. 开发历程（六阶段）

1. **串口非阻塞重构与帧同步**：修复暴力清空串口导致的半截数据帧截断，实现字符级拼接 + 行终止符判断。
2. **底盘全域非阻塞化**：剔除 `delay()`，新增 `STATE_WAITING` 与 `initiateWait()`，舵机动作平滑。
3. **红外盲区门禁与去抖**：9 秒起步屏蔽 + 投放后时间戳双重过滤。
4. **正方体旋转测距异常与 K230 算力极限**：正方体倾斜 45° 致外接框面积虚增，回滚纯 YOLO 方案，引入 `machine.WDT` 自愈，确立「二维对准 + 定高抓取/重试」。
5. **第二次转弯五步闭环重写**：`STATE_PARK_TURN2` 拆解为五段状态链，靠传感器跳变推进。
6. **电池电压衰减与静摩擦死区消除**：`motorControl` 加入 `DEADZONE_PWM = 115` 下限截断 + 瞬时启动脉冲。
